# CodeAlpha Calculator

A responsive calculator built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Modulus (%)
* Clear Screen (C)
* Delete Last Character (⌫)
* Keyboard Support
* Responsive Design
* Modern User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

CodeAlpha_Calculator/

├── index.html

├── style.css

├── script.js

└── README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
